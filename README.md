# Lethe — заметки, которые никто не прочитает через плечо

*Лета — река забвения в греческом подземном мире. Слова растворяются на экране, как в её водах,
но в заметке остаются целиком.*

Минималистичные заметки для Android 13+ (сделано под Samsung S24, Android 17 / One UI 9).
Главное в приложении — режим исчезающих слов: на белом полотне видно только слово,
которое вы печатаете сейчас. После пробела оно плавно растворяется.

## Как собрать и поставить на телефон

1. Распакуйте архив и откройте папку `Lethe` в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle. Studio сама скачает Gradle 9.6, AGP 9.5 и,
   если потребуется, Android SDK 37: просто соглашайтесь на предложения установить.
3. На телефоне включите режим разработчика: Настройки → Сведения о телефоне →
   Сведения о ПО → 7 раз нажмите «Номер сборки». Затем в «Параметрах разработчика»
   включите «Отладку по USB» (или «Беспроводную отладку»).
4. Подключите телефон, выберите его в списке устройств сверху и нажмите ▶ Run.

APK без кабеля: Build → Generate App Bundles or APKs → Build APK(s). Готовый файл
лежит в `app/build/outputs/apk/debug/app-debug.apk`, его можно скинуть на телефон и установить.

## Как устроено

| Экран | Что делает |
|---|---|
| Список (`MainActivity`) | Все записи с датой и временем, новые сверху. Тап открывает, долгое нажатие удаляет. |
| Исчезающие слова (`WriteActivity`) | Белое полотно и клавиатура. Слово исчезает после пробела или Enter. «Готово» или жест «назад» открывают запись целиком. |
| Заметка (`NoteActivity`) | Весь текст, можно править. Кнопки: «продолжить скрытно» (глаз), поделиться, удалить. |

- **Хранение:** каждая запись — обычный файл `.txt` (UTF-8) во внутренней памяти приложения:
  `files/notes/<время создания>.txt`. Автосохранение во время набора.
- **Только вертикально:** все экраны зафиксированы в портретной ориентации.
- **Приватность:**
  - Исчезнувшие слова нельзя стереть или исправить, курсор нельзя увести назад.
  - Клавиатура получает флаг «не запоминать ввод» (режим инкогнито Samsung Keyboard / Gboard).
  - Содержимое не попадает в превью «Недавних приложений».
- **Ярлык:** долгое нажатие на иконку → «Новая запись» открывает режим набора сразу.

## Шрифт

Calibri — платный шрифт Microsoft, его нельзя встраивать в приложение. Поэтому
используется **Carlito** (лицензия SIL OFL): он метрически совместим с Calibri и выглядит
почти так же. Если у вас есть свой `calibri.ttf` (например, из Windows), положите его
вместо `app/src/main/res/font/carlito_regular.ttf` под тем же именем.

## Что настроить под себя

- Размер слова: `android:textSize="30sp"` в `res/layout/activity_write.xml`.
- Скорость исчезания: `DISSOLVE_MS` в `WriteActivity.java`.
- Цвета: `res/values/colors.xml`.
